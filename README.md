### ABOUT

I’m a technology enthusiast with a strong interest in software development, networking, and telecom systems, combining hands-on coding with a solid understanding of how real-world systems operate. My work focuses on practical solutions that don't require heavy installations—just open and interact.

My GitHub reflects my journey of building practical, project-driven solutions while continuously strengthening my fundamentals across development, networking, and system architecture.Currently developing AI,ML model and integrate with web and app to automate the network health monitoring, fault detection and config updation.

**Core Competencies:** Python • JavaScript • Linux • React • TensorFlow • React Native • AWS • Docker • Blockchain • Solidity

### APPROACH

My work philosophy centers on three principles:

**Practical First** — Every project should be easy to run, test, and understand, with minimal setup overhead. I prioritize browser-based tools, scripts, and lightweight deployments that reduce friction while still delivering meaningful functionality.

**Production Oriented** — Proofs of concept are useful, but reliable systems matter more. I focus on complete, deployable solutions with attention to stability, observability, and real-world usability, informed by hands-on experience with networking and system operations.

**Human-Centered** — Technology should simplify workflows, not complicate them. This mindset guides my approach to building tools and applications that are intuitive, accessible, and aligned with how users and operators actually work
